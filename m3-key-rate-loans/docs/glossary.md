# Глоссарий (своими словами)
| Термин | Что это |
|---|---|
| Ключевая ставка (КС) | Главная ставка ЦБ; от неё зависят ставки по кредитам и депозитам |
| Плавающая ставка | Ставка кредита, которая меняется вслед за индикатором: «КС + маржа» |
| Маржа | Надбавка банка к КС, фиксирована в договоре |
| Пол (floor) | Минимальная ставка: защищает банк, когда КС падает |
| Потолок (cap) | Максимальная ставка: защищает клиента, когда КС растёт |
| Дата фиксации | День, на который берут КС для следующего процентного периода |
| Lookback | Сдвиг фиксации раньше начала периода, чтобы успеть посчитать и уведомить |
| Процентный период | Срок, за который начисляются проценты по одной ставке (у нас месяц) |
| АБС | Автоматизированная банковская система: где живут договоры и графики |
| SOAP | Протокол обмена XML-сообщениями в «конверте» (Envelope); строгий контракт через WSDL |
| WSDL | XML-описание SOAP-сервиса: какие методы, параметры, адрес |
| SOAP Fault | Стандартное сообщение об ошибке в SOAP |
| SOAPAction | HTTP-заголовок, который говорит серверу, какой метод вызываем |
| SoapUI | Программа для ручных запросов к SOAP- и REST-сервисам |
| REST | Стиль API поверх HTTP: ресурсы по URL, методы GET/POST, чаще JSON |
| Средневзвешенная ставка | Средняя ставка, где большие кредиты весят больше: Σ(остаток × ставка) / Σ остаток |
