# Дашборд в Yandex DataLens: требования и как собрать

Макет: [dashboard/dashboard-mockup.png](../dashboard/dashboard-mockup.png) (нарисован в matplotlib по тем же данным). Сам дашборд в DataLens собирается за ~1 час по шагам ниже — это часть «доработай сам» (DEFENSE.md, §6). Живой ссылки на опубликованный дашборд в репозитории пока нет.

## 1. Для кого и какие решения принимает
| Пользователь | Вопрос | Решение |
|---|---|---|
| Руководитель антифрода | Справляется ли команда? | Нужен ли ещё аналитик, менять ли пороги |
| Аналитик правил | Какое правило шумит? | Поднять порог, отключить правило |
| Продукт / поддержка | Сколько честных клиентов мы беспокоим? | Пересмотр маршрута SMS |

## 2. Метрики (определения)
| Метрика | Формула | Источник |
|---|---|---|
| Алертов в день | COUNT(alerts) / дней | `daily_metrics.csv` |
| Доля подтверждённых | confirmed_fraud / alerts | `daily_metrics.csv` |
| Ложные срабатывания | false_positives / alerts | `daily_metrics.csv` |
| Нагрузка на аналитика | analyst_alerts × 12 мин | `daily_metrics.csv` |
| Время до решения | AVG(minutes_to_decision) | `daily_metrics.csv` |
| Точность правила | fraud_hits / alerts | `rule_hits.csv` |

## 3. Как собрать в DataLens
1. `psql -d m5 -f dashboard/export.sql` — получите `dashboard/daily_metrics.csv` и `dashboard/rule_hits.csv` (уже лежат в репозитории).
2. DataLens → Подключения → **Файлы** → загрузить оба CSV. Проверить типы полей: `day` — дата, числа — целые / дробные.
3. Датасет из `daily_metrics`: добавить вычисляемые поля `Доля подтверждённых = SUM([confirmed_fraud]) / SUM([alerts])`, `Часы аналитика = SUM([analyst_alerts]) * 12 / 60`.
4. Чарты: 4 индикатора (KPI), столбчатая диаграмма с накоплением «алерты по дням, цвет = route», горизонтальные столбцы «точность правил».
5. Дашборд: KPI в верхний ряд, под ними два графика; селектор по `route` и по дате в одну строку над графиками.
6. Опубликовать по ссылке, вставить ссылку в README.

## 4. Нефункциональные требования
- Обновление: раз в сутки (в учебной версии — вручную из CSV).
- Данные без персональной информации: только агрегаты по дням и правилам.
