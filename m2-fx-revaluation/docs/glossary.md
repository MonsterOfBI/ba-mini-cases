# Глоссарий (своими словами)
| Термин | Что это |
|---|---|
| Официальный курс ЦБ | Курс рубля к валюте, который ЦБ устанавливает каждый рабочий день; по нему ведут учёт |
| XML | Текстовый формат данных с тегами `<Valute>…</Valute>`; ЦБ отдаёт курсы в XML |
| XSD | Схема, которая описывает, какие теги и в каком виде должны быть в XML; по ней проверяют файл |
| windows-1251 | Старая кодировка кириллицы; в ней ЦБ отдаёт XML |
| Nominal | За сколько единиц валюты указан курс (1 доллар, 100 тенге) |
| Монетарная статья | То, что будет погашено деньгами: долги, деньги на счёте. Переоценивается |
| Аванс | Предоплата; будет погашена товаром или услугой, поэтому не переоценивается |
| Переоценка | Пересчёт валютной статьи в рубли по новому курсу |
| Курсовая разница | Насколько изменилась рублёвая оценка статьи из-за курса |
| 91.01 / 91.02 | Прочие доходы / прочие расходы — туда идут курсовые разницы |
| 60.21 / 62.21 | Расчёты с поставщиками / покупателями в валюте |
| ПБУ 3/2006 | Стандарт бухучёта про активы и обязательства в валюте |
| LATERAL | Подзапрос в SQL, который выполняется для каждой строки слева — удобно для «последний курс на дату» |
| LAG | Оконная функция: значение из предыдущей строки (здесь — предыдущий курс по документу) |
| CTE (WITH) | Именованный шаг запроса, чтобы читать SQL по шагам |
