# 2. Пользовательские истории

**US-01 (Must). Курсы без ручного копирования.** Как бухгалтер, я хочу, чтобы официальные курсы ЦБ на все нужные даты загружались автоматически, чтобы не копировать их с сайта и не ошибаться в датах.
```gherkin
Сценарий: курс на рабочую дату
  Дано ЦБ опубликовал курс USD на 30.09.2026 = 84,4283
  Когда запускается загрузка курсов
  Тогда в таблице fx_rates есть строка 2026-09-30, USD, 84.4283

Сценарий: курс на воскресенье
  Дано отчётная дата 01.11.2026 приходится на воскресенье
  Когда расчёт запрашивает курс на эту дату
  Тогда используется курс, установленный на 31.10.2026 (BR-03)

Сценарий: ЦБ поменял формат ответа
  Дано ответ ЦБ не проходит проверку по XSD
  Когда запускается загрузка
  Тогда загрузка останавливается с ошибкой и старые курсы не перезаписываются
```

**US-02 (Must). Переоценка на конец месяца.** Как бухгалтер, я хочу получить расчёт курсовых разниц по каждому открытому документу на последнее число месяца, чтобы сделать проводки одним пакетом.
```gherkin
Сценарий: переоценка долга поставщику
  Дано долг поставщику 100 000 CNY признан 15.09.2026 по курсу 12,5353
  И 30.09.2026 курс 12,5764
  Когда запускается переоценка на 30.09.2026
  Тогда курсовая разница = −4 110,00 ₽ (расход), проводка Дт 91.02 Кт 60.21

Сценарий: аванс не переоценивается
  Дано выдан аванс поставщику в CNY (счёт 60.22)
  Когда запускается переоценка
  Тогда аванс не попадает в расчёт и показывается в списке «не переоценивается: аванс»

Сценарий: долг погашен в отчётную дату
  Дано долг погашен 30.09.2026
  Когда запускается переоценка на 30.09.2026
  Тогда по документу есть только разница при погашении, без переоценки (BR-06)
```

**US-03 (Should). Проверки перед закрытием месяца.** Как главный бухгалтер, я хочу видеть список проблем в данных до проведения переоценки, чтобы не закрывать месяц с ошибкой.
```gherkin
Сценарий: нет курса на отчётную дату
  Дано на 31.10.2026 не загружен курс EUR
  Когда запускаются проверки
  Тогда проверка «нет курса ровно на отчётную дату» показывает 1 и закрытие месяца блокируется

Сценарий: всё в порядке
  Дано все курсы загружены, авансов в расчёте нет
  Когда запускаются проверки
  Тогда все 4 проверки показывают 0
```

## Нефункциональные требования
- Загрузка курсов за месяц — не дольше 1 минуты; при недоступности ЦБ — 3 повтора с паузой 1 минута, затем уведомление.
- Курсы хранятся с 4 знаками, как публикует ЦБ; рубли — до копеек.
- Расчёт воспроизводим: те же данные → те же цифры (проверяется `tests/check_revaluation.py`).
