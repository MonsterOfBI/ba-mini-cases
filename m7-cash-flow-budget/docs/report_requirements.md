# Требования к отчётам БДДС и платёжному календарю

## 1. Проблема и цель
ООО «Ромашка-Опт» (вымышленная) узнаёт о нехватке денег, когда платёж поставщику уже не проходит. Бюджет составляется раз в год в Excel по месяцам, факт с планом сравнивают нерегулярно. **Цель:** видеть кассовый разрыв минимум за 3 недели и принимать решение (перенос, кредит, ускорение оплат от покупателей) заранее.

## 2. Пользователи и их вопросы
| Пользователь | Вопрос | Отчёт |
|---|---|---|
| Финансовый директор | Хватит ли денег в ближайшие 8 недель? Где разрыв? | Платёжный календарь |
| Финансовый директор, ГД | Насколько факт расходится с бюджетом и почему? | План-факт |
| Руководитель ЦФО | Сколько я потратил против плана? | План-факт с фильтром по ЦФО, Сводная_ЦФО |
| Казначей | Какие платежи можно перенести, если денег не хватает? | Платежи_план с приоритетами |

## 3. Функциональные требования
| ID | Требование | Где реализовано |
|---|---|---|
| FR-01 | План-факт по каждой статье и месяцу: план, факт, отклонение в рублях и %; итоги поступлений, выбытий, чистого потока | План_факт |
| FR-02 | Подсветка отклонений больше порога (параметр, по умолчанию 5 %) | План_факт, условное форматирование |
| FR-03 | БДДС на полугодие: факт по закрытым месяцам + прогноз по остальным; остаток на начало и конец месяца | БДДС_прогноз |
| FR-04 | Чистый поток по видам деятельности: операционная, инвестиционная, финансовая | БДДС_прогноз |
| FR-05 | Платёжный календарь по неделям (с понедельника) на 8+ недель: поступления, выбытия по приоритетам, остаток | Платёжный_календарь |
| FR-06 | Статус недели: «РАЗРЫВ», если остаток < 0; «ниже резерва», если меньше неснижаемого остатка | Платёжный_календарь, БДДС_прогноз |
| FR-07 | Сценарии: стоимость овердрафта на разрыв; эффект переноса платежей приоритета 3; доход от размещения излишка | Сценарии |
| FR-08 | Версии бюджета не перезаписываются: «Бюджет v1» хранится как утверждён, прогноз — отдельная версия | Справочники, План |
| FR-09 | Контроль целостности: выбытия календаря = выбытия БДДС за те же месяцы | Платёжный_календарь, строка «Проверка» |

## 4. Бизнес-правила
- BR-01. Срок платежа на выходной переносится на следующий рабочий день (налоги по ЕНП 28-го: 28.11.2026 — суббота → 30.11).
- BR-02. Приоритеты платежей: 1 — налоги, зарплата, кредит (переносить нельзя); 2 — платежи по договорам; 3 — переносимые (оборудование, маркетинг).
- BR-03. Неснижаемый остаток 2 млн ₽ — политика компании (примерно 3 дня выручки); ниже него — сигнал, ниже нуля — разрыв.
- BR-04. Выбытия вводятся положительными числами, знак задаёт направление статьи.

## 5. Нефункциональные требования
- Обновление факта: еженедельно, по понедельникам, выгрузкой из 1С (в модели — вручную).
- Все расчёты — формулами, без ручных чисел в отчётных листах; исходные данные — только на жёлтых ячейках.
- Книга открывается в Excel 2016+ и LibreOffice Calc без ошибок формул.

## 6. Ежемесячный цикл (после утверждения бюджета)
1. До 5-го рабочего дня: факт за прошлый месяц загружен, статьи разнесены.
2. ФЭО обновляет план-факт и объясняет отклонения больше порога с руководителями ЦФО.
3. ФЭО обновляет Платежи_план (прогноз) и платёжный календарь, ФД решает по неделям «ниже резерва».

## 7. Открытые вопросы

2. Нужен ли календарь по дням для крупных платежей (> 1 млн ₽)?
3. Проценты по кредиту — операционная или финансовая деятельность (учётная политика)?
