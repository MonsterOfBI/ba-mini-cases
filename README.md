# Мини-кейсы бизнес-аналитика

> **Учебные кейсы.** Компании вымышленные, данные синтетические или открытые, внедрения не было. Первые версии собраны вместе с ИИ-ассистентом; что я проверил и переделал сам — в разделе «Как сделано» в README каждого кейса.

Каждый мини-кейс тренирует один навык и делается за 6–15 часов. Большие кейсы лежат отдельными репозиториями, ссылки в [профиле](https://github.com/MonsterOfBI).

**Как смотреть кейс:** в папке `README.md` — суть за минуту и цифры, `DEFENSE.md` — вопросы с собеседования по кейсу и мои ответы, `CHANGELOG.md` — что менялось.

## In English
A collection of small learning case studies by a junior business analyst: one skill per case (BPMN/DMN, SQL, requirements, API specs, Excel models) in fintech, corporate finance and a few non-finance domains. Companies are fictional and data is synthetic or public. Each folder has a README with an English summary and a DEFENSE file with interview questions and answers.
